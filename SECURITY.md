# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 16.x    | :white_check_mark: |
| < 16.0  | :x:                |

## Reporting a Vulnerability

I take the security of this portfolio and associated services seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

- **Contact**: Reach out privately to the maintainer via the contact form on [axe-vin.vercel.app](https://axe-vin.vercel.app) or via email.
- **Please do not open public GitHub issues** for security vulnerabilities, secret leaks, or sensitive flaws.

### What to Include in Your Report

1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or Proof of Concept (PoC) to reproduce the issue.
3. Affected endpoints, components, or files.

### Response Timeline

- **Acknowledgment**: Within 48 hours.
- **Triage & Fix**: A fix will be developed, tested, and deployed as quickly as possible.
- **Disclosure**: Coordinated public disclosure after remediation is deployed.

Thank you for helping keep this project and its users safe!
